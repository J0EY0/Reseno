# Current Task Status

## 当前阶段目标

继续把 ResuMate 打磨成接近真实产品的状态。当前重点是稳定 UI/UX、数据结构、前后端 API 职责、A4 预览和导出能力。

## 已完成

- 登录页只提交用户名和密码；认证、JWT 签发与刷新失效均由后端处理。
- 主要路由已拆分：简历列表、简历详情、模板列表、模板详情、回收站、大模型配置、设置页。
- 简历列表和模板列表支持搜索、创建、导入、选择、删除、批量删除、回收站和分页。
- 简历编辑器支持基本信息、头像、自定义字段、模块增删改名、折叠、排序和富文本要点编辑。
- 中间区域支持真实 A4 预览；当前 PDF 导出会保存版本，通过隐藏的 `/pdf-export` iframe 触发浏览器原生打印，后端另提供 Playwright 服务端导出接口。
- 模板系统支持内置模板、自定义模板、默认模板、只读内置模板、创建可编辑副本、布局/字体/颜色/背景/装饰图片配置。
- 大模型配置已收敛为云端 provider、本地 OpenAI-compatible runtime、自定义云端 API 三种模式；云端和本地 provider 由后端 manifest 和模型发现接口驱动。
- Agent 对话栏已接入后端接口，输入框支持附件和模型选择。
- Agent 普通 JSON 与 SSE 流式响应格式已固定。
- i18n 已拆分为动态 JSON；登录页默认跟随系统语言，不支持时 fallback 到英文。
- API helper 已集中，默认请求同源后端 `/api`，开发环境由 Vite 代理到本地后端。
- 编辑页和模板页的桌面端滚动已按预览区高度约束：左侧超出后内部滚动且不联动右侧，折叠动画和预览缩放已稳定。
- 页面初始化已改为按路由查询；后端简历生命周期、模板目录和默认模板状态也已拆成独立领域模块。
